# Chapter 3. Feature Engineering

This week introduces the core idea that language must be converted into numerical representations before it can be used in machine learning and retrieval systems.

The path is simple but important: text is tokenized, vocabulary is built, document features are counted, and those feature vectors can be used for classification, clustering, ranking, and later semantic retrieval.

The chapter below focuses on the conceptual foundations: document-term matrices, n-grams, TF-IDF, and the transition from sparse lexical vectors to dense embeddings.
