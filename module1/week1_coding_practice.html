1.2 Language as Data#

This activity is a short reflection exercise, not a full Python tutorial.

You will use a few basic Python string operations to explore how computers (python) interact with text.

Focus on the bigger question:

What information about language is easy for a computer to detect, and what requires deeper analysis?

How to use this notebook#

  1. Download this file as ipynb

  2. Open this file in Google Colab (upload to https://colab.research.google.com/) or VS Code.

  3. Choose a Python kernel.

  4. Run each code cell from top to bottom, or use Run All.

  5. No extra files, installs, or database setup are required.

This activity is self-contained and works from a clean checkout or a downloaded notebook.

1. Can Python Understand Language?#

Before running the code, look at these two sentences:

  • “I love this movie.”

  • “I do not love this movie.”

Think first#

  1. Which sentence is positive?

  2. Which sentence is negative?

  3. What word appears in both sentences?

  4. If a program only searched for the word love, would that be enough to understand the meaning?

text1 = "I love this movie."
text2 = "I do not love this movie."

print("love" in text1)
print("love" in text2)

True
True

What happened?#

Python found the word love in both sentences.

But the two sentences do not communicate the same meaning.

Question: What information is Python missing?

2. Language Is Data#

Python stores text as strings.

Before running the code below, predict:

  1. What data type is text?

  2. How many characters do you think it contains?

  3. Does Python treat spaces and punctuation as characters?

text = "Natural language is messy!"

print(type(text))
print(len(text))

<class 'str'>
26

Think about the output#

  • What change when we use .lower()?

  • What does .split() consider a separate unit?

  • What happens to the punctuation?

  • Is splitting on spaces always enough to identify words?

print(text.lower())
print(text.upper())
print(text.split())

natural language is messy!
NATURAL LANGUAGE IS MESSY!
['Natural', 'language', 'is', 'messy!']

3. Same word, different meaning#

Consider:

  • “Apple released a new laptop.”

  • “She ate an apple.”

Think first#

Does the word apple mean the same thing in both sentences?

text1 = "Apple released a new laptop."
text2 = "She ate an apple."

print("apple" in text1.lower())
print("apple" in text2.lower())

True
True

Python can detect the same sequence of characters.

But can it determine what apple refers to?

This is an example of why context matters in NLP.

4. Small changes, big changes in meaning#

  • Which changes affect meaning?

  • Which affect tone?

  • Which might affect a model?

  • Which could be normalized away?

  • Should they always be normalized away?

sentences = [
    "This is good.",
    "This is not good.",
    "This is very good.",
    "This is good?",
    "This is GOOD!!!"
]

for sentence in sentences:
    print(sentence)

This is not good.

This is good?

5. What can simple string operations tell us?#

We can build a simple rule detecting the word amazing in the reviews.

But does it correctly determine sentiment in every example?

What would a more intelligent NLP system need to consider besides individual words?

reviews = [
    "Amazing product! 😍",
    "Not amazing at all.",
    "The product arrived yesterday.",
    "AMAZING!!!",
]

for review in reviews:
    print(review, "->", "amazing" in review.lower())

Amazing product! 😍 -> True
Not amazing at all. -> True
The product arrived yesterday. -> False
AMAZING!!! -> True

What You Just Discovered#

Basic Python lets us:

  • store text

  • inspect text

  • search text

  • transform strings

  • split text into pieces

But language meaning depends on more than characters and keywords.

NLP gives us methods for representing and analyzing that additional structure.

strings → tokens → features → vectors → models
